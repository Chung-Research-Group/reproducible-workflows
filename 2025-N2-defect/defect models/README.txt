Name of the models: {model_type}_{number_of_removed_cluster}_{defect_concentration}.cif

model_type: 1 --> unit cell ; 2 --> 2*2*2 supercell ; 3 --> 3*3*3 supercell

number_of_removed_cluster: number of cluster(s) removed from the pristine model

defect_concentration: e.g., _250 means r_d = 0.25 = 25%, _148 means r_d = 0.148 = 14.8%
